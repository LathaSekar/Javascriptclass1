for ..in loop:
This loop iterates over the keys or property names of an object
const person={name:"santhosh",
              age:22,
              city:"Tirupur"};
for (let key in person){
console.log(key + "=>"+person[key]);
}
output:
name=>santhosh
age=>22
city=>Tirupur

for ..of
This loop iterates over the values of iterable objects like arrays,strings,maps and sets
const colors=["red","blue","green"];
for (let color of colors){
console.log(color);
}
output:
red
blue
green

while loop:
This loop checks the condition first,and then runs the code only if the condition is true
while(condition){
}
example:
let i=1;
while (i<=5){
console.log(i);
i++;
}
output:
1
2
3
4
5
do while
it runs the loop body first before checking the condition
do{
//...
}while(condition);
example:
let i=1;
do{
console.log(i);
i++;
}while(i<=5);
output:

2

5

3.Exception handling
try -code that might throw an error
catch-what to do if an error happens
finally-always run code afterward
throw-manually create your own errors
try{
//..
}catch(error){
//..
}finally{
//..
}
example1:
try{
notAFunction();
}
catch(error){
console.log("error occurred:",error);
}
output:
error occurred: ReferenceError: notAFunction is not defined
