Javascript Functions:
function is a reusable block of code that performs a task
1.Function declaration:
function greet(name){
console.log("Hello "+ name);
}
greet("Santhosh");
output:
Hello  Santhosh
name-parameter
santhosh-argument

2.Function with return values:
 function add(x,y){
 return x+y;
 }
 const sum=add(5,4);
 console.log(sum);
 output:
 9

 3.Function expression:
 const multiply=function(a,b){
 return a*b;
 };
 console.log(multiply(33,33));
 output:
 1089

 4.Arrow function:
 const square= n => n*n;
 console.log(square(5));
 output:
 25

 5.default parameters:
 function greet(name="Guest"){
 console.log("Hello  " + name);
 }
 greet();
 greet("santhosh");
output:
 Hello  Guest
Hello  santhosh

6.IIFE(Immediately Invoked Function Expression)
that is defined and executed right away
(function(){
//..
})();
Example:
(function(){
var secret="hello";

})();
console.log(secret);
output:
ReferenceError: secret is not defined
