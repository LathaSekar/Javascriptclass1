DOM Traversal & Manipulation - Real Time Examples

 1. `element.remove()` — Remove an element from the DOM
<!DOCTYPE html>
<html>
<body>
  <div id="notification">🔔 You have a new message!</div>
  <button onclick="dismissNotification()">Dismiss</button>

  <script>
    function dismissNotification() {
      const notification = document.getElementById("notification");
      notification.remove(); // Removes the element completely from DOM
    }
  </script>
</body>
</html>

2. `element.parentNode` — Access the parent of an element
<ul id="task-list">
  <li>Buy groceries <button onclick="deleteTask(this)">❌</button></li>
  <li>Walk the dog <button onclick="deleteTask(this)">❌</button></li>
</ul>

<script>
  function deleteTask(btn) {
    const listItem = btn.parentNode; // Gets the <li> that contains the button
    listItem.remove();
  }
</script>

3. `element.childNodes` — Get all child nodes (including text nodes)
<div id="card">
  <h2>John Doe</h2>
  <p>Developer</p>
  <span>New York</span>
</div>

<script>
  const card = document.getElementById("card");
  const children = card.childNodes; // NodeList: includes text nodes + elements

  children.forEach(node => {
    if (node.nodeType === 1) { // nodeType 1 = Element node
      console.log("Tag:", node.tagName, "| Text:", node.innerText);
    }
  });

  // Output:
  // Tag: H2  | Text: John Doe
  // Tag: P   | Text: Developer
  // Tag: SPAN| Text: New York
</script>

 4. `element.firstChild` — Get the very first child node

<ul id="menu">
  <li class="active">Home</li>
  <li>About</li>
  <li>Contact</li>
</ul>

<script>
  const menu = document.getElementById("menu");

  // firstChild may return a text node (whitespace), so use firstElementChild
  const firstItem = menu.firstElementChild; // ✅ Safer - skips text nodes
  firstItem.style.backgroundColor = "yellow"; // Highlights "Home"

  console.log(menu.firstChild);        // ⚠️ Text node (whitespace)
  console.log(menu.firstElementChild); // ✅ <li>Home</li>
</script>
```
Real-world use: Highlighting the first menu item on page load, auto-focusing the first form field.

## 5. `element.nextSibling` — Get the next sibling node

```html
<div id="steps">
  <p id="step1">Step 1: Fill the form</p>
  <p id="step2">Step 2: Review details</p>
  <p id="step3">Step 3: Submit</p>
</div>

<script>
  let current = document.getElementById("step1");
  current.style.color = "blue"; // Highlight current step

  function goToNextStep() {
    // nextSibling may return text nodes — use nextElementSibling instead
    const next = current.nextElementSibling; // ✅ Skips whitespace text nodes
    if (next) {
      current.style.color = "black";
      next.style.color = "blue";
      current = next;
    } else {
      alert("All steps complete! ✅");
    }
  }
</script>

<button onclick="goToNextStep()">Next Step ➡️</button>

Reference:
`firstChild` and `nextSibling` include **whitespace text nodes**. 
Always prefer `firstElementChild` and `nextElementSibling` when you want only HTML elements.
