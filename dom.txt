Changing context:
change Text:
inner text gets or sets only the visible text content inside and element
document.getElementById("title").innerText="NewTitle";
Change HTML:
Inner HTML gets or sets the HTML content including tags inside an element
document.getElementById("title").innerHTML="<b>boldtext</b>";

Changing CSS style:
document.getElementById("title").style.color="red";
document.getElementById("title").style.fontsize="30px";

Addding new element:
let newpara=document.createElement("p");
newpara.innerText="This is my new para";
document.body.appendChild(newpara);
